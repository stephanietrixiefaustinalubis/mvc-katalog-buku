# Sistem Pengelolaan Katalog Buku (MVC PHP Native)

Aplikasi inventaris data buku berbasis PHP Native dengan arsitektur MVC, PDO, validasi form, dan pencatatan Git terarah.

## Kebutuhan Lingkungan
- PHP >= 8.0
- MariaDB / MySQL
- Web Server XAMPP / Laragon

## Petunjuk Instalasi
1. Pindahkan folder `katalog-buku` ke direktori web server lokal (`htdocs` atau `www`).
2. Impor basis data `database/katalog_buku.sql` melalui phpMyAdmin.
3. Buka URL: `http://localhost/katalog-buku/public/index.php`.

## Histori Pengembangan Git
Histori commit dapat dilihat menggunakan perintah:
`git log --oneline --graph --decorate`
